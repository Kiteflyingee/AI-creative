# 决策记录（decisions）

> 版本：v0.4 · 2026-11-11。本文是第一版实现的依据：其余文档与本文冲突时，以本文为准。
>
> - v0.4 的变化：首发改为海外；接入 Google（Gemini Omni 1.2 Flash 视频、Nano Banana 2.1 图片），与火山（Seedance 2.5、Seedream 5.0 pro）并存；模型组合由服务端配置并记录在项目上；大模型与火山接入地址可配置（D-45 至 D-50）。
> - 2026-11-13 接入方式更新：Google 模型只使用 Google Cloud Vertex AI 全局端点与 ADC，移除原 Gemini API 直连；默认三类模型使用 Vertex，其他供应商保留（D-57 / D-58，覆盖旧条目中的 Google 接入方式与默认配置）。
> - 同日最终架构更新：取消 New API，改为 AI SDK 显式 Provider + 原生供应商适配器直连（D-60，取代 D-59）；默认仍为 Vertex 全局端点和 ADC。

> - 等待体验更新：故事线和故事板按服务端真实阶段实时显示创作进展、等待时间、修正与限流状态（D-64）。
> - v0.3 的变化：按 Kickart 的设计重做生成方式（先准备参考图 → 逐镜头生成 → 合成），视频模型改为通用框架，积分与运营后台搁置，开始写代码。
> - 已定决策用 `D-xx`，待定用 `P-xx`。v0.2 中被替换或搁置的条目保留编号，并在 §3 说明去向。
> - “来源”一栏：`v0.1 原文` 指已删除的 `交接包/` 与 `设计方案.md`（见 git 历史）；`规划对话` 指 2026-11-10 与产品负责人的确认对话。
> - 第一版的实际实现见 [07-第一版实现说明.md](07-第一版实现说明.md)；模型事实见 [06](06-模型能力与约束.md)（已更新到 v0.3）。02–05、mvp-flows、first-batch-tasks 保留 v0.2 内容并在开头加了提示，冲突时以本文和 07 为准。

| D-38 | 口播由视频模型自带的声音生成；所有镜头使用同一段音色描述；TTS 接口预留，第一版不实现 | Seedance 2.5 自带声音 | 规划对话 |
| D-14（v0.3 改） | 重做镜头进入第一版：只重新生成选中的镜头，其他镜头不动；每个镜头保留全部片段版本，可以对比、可以回退，回退只重新合成 | 原 P-01：验收故事要求“只重做第三镜头” | 规划对话 |
